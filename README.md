# FastAPI + PostgreSQL Backend API

A RESTful backend API built with FastAPI and PostgreSQL. The project implements authentication, database migrations, and a modular architecture suitable 
for scalable backend systems.

## Features

- User authentication using JWT
- Secure password hashing
- PostgreSQL integration
- SQLAlchemy ORM
- Alembic database migrations
- RESTful API design
- Environment-based configuration
- Clean modular project structure

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Pydantic
- Uvicorn
- JWT Authentication
